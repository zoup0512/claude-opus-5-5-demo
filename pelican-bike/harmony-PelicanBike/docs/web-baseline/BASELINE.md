# Pelican Bike 原版 Web 视觉基线

## 1. 采集范围与环境

- 源项目：`D:\workspace\My\h5\claude-opus-5-5-demo\pelican-bike`
- 构建产物：源项目未跟踪目录 `dist/index.html`；未修改任何已跟踪 H5 源码。
- 浏览器：本机 Google Chrome，Playwright Core 驱动，headless WebGL2，SwiftShader ANGLE。
- 页面视口：`1440 × 900 CSS px`
- 页面截图：`1440 × 900 PNG`
- `deviceScaleFactor`：`1`
- 语言/配色：`zh-CN`、dark color scheme
- 采集日期：2026-10-04
- 公共固定 URL 参数：

```text
?autostart=1&freeze=1&dt=0.0166667&q=high&speed=7.5&time=<hour>&cam=<mode>
```

参数含义：

- `autostart=1`：跳过开场并进入骑行。
- `freeze=1`：冻结昼夜时钟，`settings.hour` 不自行变化；骑行和角色动画仍按固定步长推进。
- `dt=0.0166667`：每帧固定约 1/60 秒。
- `q=high`：原版“精美”画质；DPR 1 环境的目标像素比为 1。
- `speed=7.5`：巡航目标 7.5 m/s，初始速度为其 60%。
- `time`：指定原版昼夜时刻。
- `cam`：指定原版镜头模式。

采集脚本在每个场景完成固定帧推进后设置 `window.__pelican.S.paused = true`，再执行 PNG 截图。原版自适应画质会按 headless 实测帧率动态降低内部 WebGL drawing buffer；外层 PNG 和 CSS 视口始终是 1440×900，因此比对时应以最终 PNG 为准。逐图状态和内部 canvas 数据保存在 `capture-manifest.json`。

## 3. 原版关键布局

- WebGL canvas 固定铺满整个视口：`position: fixed; inset: 0; width/height: 100%`。

## 6. 复现方式

直接运行脚本即可；它会在需要时以 `npm ci` 安装锁定依赖、执行 `build.mjs`、在随机本地端口启动静态服务器、完成截图后关闭服务器。若源项目原先没有 `node_modules` / `dist`，脚本会在结束时清理这些临时目录，不留下源码仓库构建痕迹。

```bash
node D:/workspace/My/harmony/harmony-PelicanBike/tools/web-baseline/capture-baseline.mjs
```

可选环境变量：

- `PELICAN_SOURCE_DIR`：源 H5 项目目录
- `PELICAN_BASE_URL`：使用已启动的页面地址；设置后跳过本地构建和内置服务器
- `PELICAN_BASELINE_DIR`：PNG/manifest 输出目录
- `PELICAN_CHROME`：Chrome/Chromium 可执行文件路径
- `PELICAN_NPM_CLI`：npm CLI JS 文件路径（非标准 Node 安装时使用）

脚本输出 12 张 PNG 和 `capture-manifest.json`，并为每张图记录实际 URL、捕获时间、镜头、动作状态、WebGL 版本和浏览器错误列表。
